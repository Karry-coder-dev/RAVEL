# External data assets

The public GitHub repository does not contain the following data files:

- Interactive-PEDES images and annotations;
- the 3K and 5K RL state pools;
- Qwen3-VL question-quality records;
- the 101 human-review records;
- cached conversation logs and evaluation archives.

Download these assets from the accompanying external data link and place them
under the corresponding directories in this folder. The expected filenames
and paths are documented by the training and evaluation configurations.

Model and retriever checkpoints are also external and should be placed under weight/.
